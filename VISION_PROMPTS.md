# Vision prompts

Generated by `scripts/render_vision.py` -- **do not edit by hand**, edit the string constants in that file and re-run it.

Object listing in the task prompt: `--perception inline`. The standalone perception probe is written either way.

Every prompt is the text-run prompt with the object descriptions replaced by pointers at the image; the rule and role wording is untouched, which is what makes the text and vision runs comparable.

## main_joint / TEACHER

Infer the learner's rule, then pick the most informative positive example. 50 of the 120 items.

Example item: `or_purple_square__other-shape__role-teacher` (image: `vision/images_224/or_purple_square__other-shape__role-teacher.png`)

```text
This is a category-learning task.
The CATEGORY RULE is: an object belongs if it is PURPLE OR it is a SQUARE.
The learner is currently using one of these two rules:
- COLOR_RULE: an object belongs if it is PURPLE, regardless of shape.
- SHAPE_RULE: an object belongs if it is a SQUARE, regardless of color.
You are not told which rule the learner is using. Infer it from their choices.
On each previous trial, the learner saw two objects and selected the one they thought belonged.

You are given one image of this task. The top section of the image, headed OBSERVED CHOICES, shows the learner's previous rounds: one row per round, numbered on the left. Each row contains the two objects the learner was shown, side by side. The object the learner selected is outlined with a thick solid black border; the object they did not select is outlined with a thin dashed grey border.

You are the TEACHER. Choose one object to show as the next POSITIVE EXAMPLE. Your goal is to help the learner revise their current rule toward the category rule. Choose the example that most directly shows something their current rule is missing.

The bottom section of the image, headed OPTIONS, shows the four objects you may choose from, labelled A, B, C and D from left to right.

First, report what you can actually see. List every object in the image in reading order: the OBSERVED CHOICES rows from top to bottom (left object before right object within a row), then the OPTIONS from left to right. Describe each object with these five fields:
- "section": "history" for an object in OBSERVED CHOICES, "option" for an object in OPTIONS.
- "position": for a history object, the row number followed by L or R, e.g. "1L", "1R", "2L", "2R"; for an option, its letter "A", "B", "C" or "D".
- "color": exactly one of red, blue, green, yellow, purple.
- "shape": exactly one of circle, square, triangle, star, hexagon.
- "selected": true if that object is outlined with the thick solid black border, false otherwise. Objects in OPTIONS are never outlined in black.
If a section of the image contains no objects, report no objects for it.

Return exactly one JSON object and no other text: {"objects":[{"section":"history" or "option","position":"1L","color":"red","shape":"circle","selected":true}, ...],"inferred_rule":"COLOR_RULE" or "SHAPE_RULE","answer":"A" or "B" or "C" or "D"}
```
